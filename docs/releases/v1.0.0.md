# Telemando 1.0.0 ✦

Primera versión pública para Android 8.0 o posterior, probada con **TCL 43C61B (Google TV)**.

- Mando con cruceta, OK, Atrás, Inicio, volumen y silencio.
- Búsqueda desde el móvil: método rápido para YouTube y pausado para Netflix.
- Emparejamiento por PIN, reconexión y tema mágico original claro/oscuro.
- Interfaz adaptada para texto grande y pantallas pequeñas.

**Limitaciones:** Prime Video se maneja con el teclado de la TV mediante la cruceta; no hay accesos directos a apps ni al sintonizador. RTVE Play no se ha probado.

**Instalación:** descarga `Telemando-v1.0.0.apk`. Si tenías la APK de *debug* de las pruebas, desinstálala antes: está firmada con otra clave y Android no permite actualizarla directamente. Esto borra el emparejamiento local; tendrás que introducir de nuevo el PIN que aparece en la TV. Las siguientes versiones públicas firmadas con esta misma clave podrán actualizarse sin desinstalar.
